Update the prices

  1. Upload the new supplier price list and/or competitor file (upload both together if you have both): upload page (sign in to GitHub), then Commit changes. Any file name is fine; the newest file of each type is used. Prepare runs by itself: wait about a minute and this page updates.
  2. Check the things above. Nothing changes in Shopify until you press Apply.
  3. Apply prices → Run workflow: mode apply, confirm APPLY (capital letters), limit 0 → the green button.

Use mode dry-run first if you want to see what would happen without changing anything. You can also run Prepare by hand: Prepare prices → Run workflow.
